本地代理网关: 127.0.0.1:1055

开发工具链一键接入指南 (零驱动提权)

将以下配置保存至本地 ~/.ssh/config，即可在系统原生终端或 VS Code Remote - SSH 中直接运行 ssh dev-server：

Host dev-server
    HostName 100.64.0.10
    User root
    # Linux / macOS 原生 OpenSSH:
    ProxyCommand nc -X 5 -x 127.0.0.1:1055 %h %p
    # Windows 10/11 原生 OpenSSH 支持 (通过代理直接打洞直连):
    # ProxyCommand connect -S 127.0.0.1:1055 %h %p
    StrictHostKeyChecking no
    ServerAliveInterval 15
DBeaver / Navicat 数据库直连设置: 在新建 MySQL/PG 连接时，勾选 网络代理 (SOCKS5)，主机填写 127.0.0.1，端口 1055，目标主机填写 100.64.0.10:3306 即可。
